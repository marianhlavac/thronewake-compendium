# About the Compendium

An unofficial, community-sourced knowledge base for **[Thronewake](https://thronewake.com)**. It grew out of an idea to feed all the Q&A between players into an LLM and produce a document summarizing everything exchanged in the chats — made available to everyone to read and edit.

## How information is marked

Statements attributed to the developer are treated as authoritative. Player-supplied details are marked *(player-reported)*, *(unconfirmed)*, or *(player note)* depending on how well-corroborated they are — see "Sourcing conventions" in [CONTRIBUTING.md](https://github.com/marianhlavac/thronewake-compendium/blob/master/CONTRIBUTING.md) for the full rules.

**1× values** are the base game numbers; on a speed world, *movement/travel speed, production per hour, and queue/build/train times* scale with the world speed, but **capacities do not** (see [Worlds & Server Speed](Worlds-and-Server-Speed.md)).

## Future of this wiki

Eventually, a knowledge base should be built into the game as its own section. The developer has stated that this is on the roadmap, together with a kind of advisor chatbot[^1].

That doesn't mean this wiki isn't worth working on, though. Its end goal could be to serve as a solid foundation for the game developer to build the in-game knowledge base later on. So if you'd like to help improve the game, contributing here could be an indirect way to do it.

## How can you help

- **Review AI-generated content.** Check a page's claims against a real source, fix what's wrong, and mark it reviewed. This is currently the single most valuable thing you can do for this wiki.
- **Correct** numbers, timings, or mechanics that are wrong or out of date.
- **Add new sourced information** — dev posts, changelog entries, or well-corroborated player reports.
- **Fix clarity issues** — better wording, missing context, broken links.
- **Write new pages** for mechanics that aren't covered yet.

See [CONTRIBUTING.md](https://github.com/marianhlavac/thronewake-compendium/blob/master/CONTRIBUTING.md) for the full guide, including for those who have never used GitHub before.
