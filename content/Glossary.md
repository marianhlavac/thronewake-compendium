# Glossary

Thronewake players use a mixture of official names and strategy-game slang. Analogy terms are community shorthand rather than separate implemented mechanics.

| Term | Meaning in Thronewake |
|---|---|
| **Awakening / world / server** | One isolated [world round](Worlds-and-Server-Speed.md). |
| **BP** | [Beginner Protection](Beginner-Protection.md). |
| **Safe Time / sleep mode** | The profile's recurring [Safe Time](Safe-Time.md) schedule. |
| **Oasis / oases** | [Wilder Sites](Wilder-Sites.md). |
| **Natars / Nataris** | [The Ancients](The-Ancients.md), by analogy with Travian's NPC faction. |
| **WW / Wonder / World Wonder** | An [Ancient Monument](Endgame-Ancient-Monument.md). Its default victory level is 100, but the world can configure another target. |
| **Plan** | An Ancient Monument Plan artefact required for Monument upgrades. |
| **Arte / artifact** | An [artefact](Artefacts.md). The game and Compendium use the spelling “artefact.” |
| **Cranny** | A [Shelter](Buildings.md#shelter), which hides resources. |
| **Chief / chiefing** | A [leader](Units.md#leaders-chiefs), or conquering a village by reducing its [loyalty](Villages-Cities-and-Expansion.md#loyalty-and-conquest). |
| **Hammer** | A large offensive army. |
| **Anvil** | A large defensive army. |
| **Scout hammer** | A large mass of scouts used for reconnaissance or counter-scouting. |
| **Fake** | A small attack intended to hide among incomings. Visibility depends on incoming troop count and the effective Rally Point threshold; see [incoming visibility](Combat.md#incoming-visibility-and-fakes). |
| **Wave** | One ordered army inside a multi-wave attack. The base Wave Builder limit is 8 and research raises it to 11. |
| **Snipe** | Reinforcements timed to land between incoming waves. |
| **Farm / farming** | Repeatedly [raiding](Combat.md#movement-types) targets for resources. |
| **Farm list / FL** | Community shorthand for saved repeated raid dispatches. Operation Plans saves up to 15 raids and sends the selected set together; it is not an unrestricted automatic farm loop. |
| **Sim / simming** | Prioritizing economic growth over raiding or warfare. |
| **Feeder** | A support village used to supply another village, within the [support limits](Marketplace-and-Trade.md#cross-player-support-limits). |
| **Crop / cropper / 9c / 15c** | Food, or a [map tile](Reports-and-Map.md#map) with 9 or 15 Food fields. |
| **4-4-4-6** | A field layout with 4 Lumberyards, 4 Quarries, 4 Foundries, and 6 Farms. |
| **Crop lock** | A state where Food production or storage constrains construction and troop upkeep. |
| **Grey zone / GZ** | The configurable central [map](Reports-and-Map.md#map) area around **0|0**. |
| **GB / GS** | Great Barracks / Great Stable; see [military buildings](Buildings.md#military-buildings). |
| **GW / GG** | Great Warehouse / Great Granary; see [storage buildings](Buildings.md#resource-and-storage-buildings). |
| **Trapper** | The Verdant [Thornsnare Grove](Verdant-Wardens.md#unique-building-thornsnare-grove) and its [traps](Combat.md#traps). |
| **Legio / Legos** | Player slang for Embermark's Emberblade. |
| **Clubby** | Player slang for Stormfang's Raider, by analogy with Travian clubswingers. |
| **Party / celebration** | A Tea Party, Grand Ball, or Stormbrew [celebration](Celebrations.md). |
| **CP / RP** | [Culture Points](Culture-Points.md) / [Research Points](Research.md). |
| **Dual / sitter** | General strategy-game slang for another person helping operate an account; it is not a distinct in-game unit or village role. |
| **The Fool** | The Trickster's Mirror [artefact](Artefacts.md#effects). |
| **Watchfire** | A recurring alliance-or-solo control event described in [Watchfires](Watchfires.md). |
| **Roman / Gaul / Teuton** | Community analogies for [Embermark](Embermark-Dominion.md), [Verdant](Verdant-Wardens.md), and [Stormfang](Stormfang-Clans.md). Thronewake has its own implemented unit and tribe rules. |
