# Glossary

Thronewake is inspired by **Travian** and its community uses a lot of Travian/Tribal-Wars jargon. This glossary maps common terms to Thronewake equivalents. Where a mapping is a player analogy rather than an official equivalence, it's marked *(analogy)*.

| Term | Meaning in Thronewake |
|---|---|
| **Awakening** | A [world / server round](Worlds-and-Server-Speed.md) (e.g. "The Fourth Awakening"). |
| **Oasis / oases** | [Wilder Sites](Wilder-Sites.md). |
| **Natars / Nataris** | [The Ancients](The-Ancients.md) — the endgame NPC faction *(analogy)*. |
| **WW / Wonder / World Wonder** | The [Ancient Monument](Endgame-Ancient-Monument.md); build it to level 100 to win. |
| **Cranny** | [Shelter](Buildings.md#shelter) — hides resources. |
| **Chief / chiefing** | [Leaders](Units.md#leaders-chiefs) / conquering villages by reducing [loyalty](Villages-Cities-and-Expansion.md#loyalty--conquering). |
| **Hammer** | A large **offensive** army. |
| **Anvil** | A large **defensive** army. |
| **Sim / simming** | Growing economically ("city builder" style) rather than raiding. |
| **Feeder** | A small support village that funnels resources/troops. |
| **Cropper / 9c / 15c** | A [village tile](Reports-and-Map.md#the-map) with extra crop fields (9 or 15). |
| **4-4-4-6** | The standard resource-field tile layout (4 Lumber, 4 Stone, 4 Metal, 6 Food). |
| **Grey zone / GZ** | The **central region** of the [map](Reports-and-Map.md#the-map), around **0\|0**. |
| **BP** | [Beginner Protection](Beginner-Protection.md). |
| **Safe time / sleep mode** | [Safe Time](Safe-Time.md). |
| **Fakes** | [Fake attacks](Combat.md#fakes) to bait defense. |
| **Snipe / sniping** | Timing troops to arrive between waves (e.g. to save a hammer or catch a defender). |
| **Farm / farming** | [Raiding](Combat.md) weak targets for resources. |
| **Farm list (FL)** | Doesn't exist by default; unlocked via the ["Operation Plans"](Research.md) research. |
| **GB / GS** | [Great Barracks / Great Stable](Buildings.md#great-buildings). |
| **GW** | [Great Warehouse](Buildings.md#great-buildings). |
| **Trapper** | The [Thornsnare Grove](Verdant-Wardens.md#unique-building-thornsnare-grove) and its [traps](Combat.md#traps-thornsnare-grove). |
| **Legio / Legos** | [Emberblade](Embermark-Dominion.md) (Embermark infantry) *(player slang)*. |
| **Clubby** | Stormfang [club](Stormfang-Clans.md) infantry. |
| **Party** | A [celebration](Celebrations.md) (Tea Party / Grand Ball) in the Festival Grounds. |
| **CP / RP** | [Culture Points](Culture-Points.md) / [Research Points](Research.md). |
| **Dual / sitter** | A co-player sharing an account; less needed here thanks to large build queues, trade routes, and [Safe Time](Safe-Time.md). |
| **The Fool** | The [Trickster's Mirror](Artefacts.md) artefact. |
| **Rats** | Weak Wilder-Site/Ancient defenders *(analogy for regenerating NPC units)*. |
| **Roman / Gaul / Teuton** | Direct equivalents of [Embermark](Embermark-Dominion.md) (balanced/strong), [Verdant](Verdant-Wardens.md) (fast/defensive), and [Stormfang](Stormfang-Clans.md) (cheap/aggressive) respectively — the stats are essentially identical to the Travian tribes. |
